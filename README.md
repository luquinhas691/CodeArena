# ⚔️ CodeArena - Battle Manager LPOO

![Status](https://img.shields.io/badge/Status-Em_Desenvolvimento-yellow?style=for-the-badge)

O **CodeArena** é um jogo de estratégia em turnos desenvolvido como projeto prático para a disciplina de **Linguagem de Programação Orientada a Objetos (LPOO)** no 3º semestre de Engenharia de Computação. O projeto visa transformar a teoria acadêmica em mecânicas de combate funcionais.

---

## 🚀 Sobre o Projeto

O jogo funciona como um **Battle Manager** (Gerenciador de Batalha). O progresso do jogador depende do seu conhecimento técnico: para atacar ou se defender, é necessário resolver desafios que validam o aprendizado de programação.

### 🧠 Conceitos de POO Implementados
O core do sistema foi arquitetado para consolidar os pilares fundamentais:
*   **Encapsulamento:** Controle rigoroso dos status e atributos dos combatentes.
*   **Herança:** Especialização de classes a partir de modelos base de entidades.
*   **Polimorfismo:** Métodos de ataque e habilidades que se comportam de forma distinta para cada classe.
*   **Abstração:** Modelagem das regras de negócio e fluxo de batalha.

---

## 🛠️ Tecnologias
*   **Linguagem:** Pure Java (JDK 17+)
*   **Ambiente:** Terminal/CLI
*   **Paradigma:** Orientação a Objetos
